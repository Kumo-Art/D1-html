## What is HTML?
- HTML stands for **Hypertext Markup Language**.
-Hypertext- text that can link to other text, thats what links are.
-Markup- Labels around the content that tell the browser what each piece is.
-HTML


## Tags vs Elements
- Tag: <h1> opens, </h1> closes. the '/' makes it a closing tag.
- Element: the opening tag + content + the closing tag together.


## Headings
- <h1> to <h6>. <h1> is the most important, <h6> the least.
- headings are about ranking not size
- dont use headings just for text size




## Nesting

-Elements can go inside other elements. Outer = parent, Inner = child.
- Close the inner one before outer. Elements never overlap


## alt text

- 'alt' describes the image. it shows if the image can't load, and screen readers read it aloud.


## Landmarks
- '<header>, '<main>', '<footer>' say what a section of the page is.
- They dont change how page looks.



## Links and Paths
- '<a href="...">' makes a link. 'href' is where it goes.
- paths start from the file I'm in:
    -'contact.html = a file right next to me
    - 'pages/contact.html' = go into the pages folder
    -'../index.html' = go up one folder


    ## Forms and inputs
    - '<label for="x">' connect to '<input id="x">'. clicking the label jumps into the input.
    - 'type' changes what an input does: text, email, number, radio, and checkbox.
